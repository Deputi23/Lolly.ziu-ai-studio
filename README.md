# LOLLY AI STUDIO v0.4 — Semi Otomatis Gratis

Isi: index.html, manifest, service worker, ikon PWA.

Fitur: detail drama, multi-karakter dan foto referensi lokal, storyboard, prompt visual dan dialog per adegan, antrean klip, tautan PixVerse dan CapCut, ekspor JSON/TXT/CSV, impor JSON, tema black-gold.

Batasan: aplikasi tidak menghasilkan video AI secara langsung. Generate video dilakukan manual di layanan eksternal menggunakan kuota gratis jika tersedia. Tidak ada API berbayar, backend, sinkronisasi cloud, atau penyimpanan video. Unggah klip hanya mencatat nama file; file asli tetap disimpan di HP.

Pemasangan: cadangkan proyek lama dengan ekspor JSON. Ekstrak ZIP, lalu ganti file index.html, manifest.webmanifest, sw.js, README.md, icon-192.png, icon-512.png pada repository GitHub. Commit dan tunggu GitHub Pages deploy. Data lokal dapat hilang jika data browser dihapus; ekspor JSON berkala.
