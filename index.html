AI Video Production

Siapkan prompt, buat klip di layanan eksternal yang memiliki kuota gratis, lalu catat statusnya di sini.

Transparansi: LOLLY AI STUDIO belum terhubung ke API generator video. Aplikasi ini menyiapkan prompt dan alur kerja; proses render tetap dilakukan manual di layanan eksternal. Kuota gratis tiap layanan dapat berubah.

Alur produksi Rp0

  1. Pilih shot dan salin prompt dari kartu storyboard.
  2. Masukkan prompt dan foto referensi karakter ke layanan AI yang menyediakan akses gratis saat digunakan.
  3. Unduh klip yang dihasilkan. Gunakan nama file E01_S01.mp4, E01_S02.mp4, dan seterusnya.
  4. Catat status setiap shot di bawah. Jangan menganggap klip selesai sebelum file benar-benar tersimpan.
  5. Susun semua klip di editor video gratis seperti CapCut versi gratis atau editor lain yang tersedia di perangkat.
